# Finale: Demonstrate the marketplace

## Goal

Bring participant projects together into a working marketplace on Stellar
testnet.

## Demo sequence

1. Explain the practical need your project addresses.
2. Show the resource your service provides.
3. Discover the service from an agent client.
4. Request the resource and show the HTTP 402 challenge.
5. Explain why the payment satisfies the agent's policy.
6. Submit and independently verify the testnet payment.
7. Show the unlocked resource.
8. Demonstrate one refused payment or invalid receipt.

## Project deliverables

- Source repository
- Setup and run instructions
- Service manifest
- Tests for successful access and rejected payments
- Testnet transaction evidence
- A short explanation of the project's intended users

## Preparation

Rehearse with another builder's service before the finale. Keep a recorded
demo available for connectivity problems and identify it as recorded when
presenting.

Use testnet accounts and synthetic demonstration data. Check that terminals,
screenshots, and recordings do not expose private keys.

## Completion checks

- Another participant can follow the setup instructions.
- The demo includes an independently verified testnet payment.
- The agent connects to another builder's service.
- The presentation explains both useful behavior and payment boundaries.
